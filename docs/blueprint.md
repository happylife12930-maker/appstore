# **App Name**: Zenith Agency

## Core Features:

- Secure Access & Collaboration: Allow registered team members to securely log in, access project data, and collaborate seamlessly across devices, leveraging Firebase Authentication for user management.
- Client Relationship Management: Create and manage comprehensive client profiles including contact details, associated projects, and financial summaries of invoices and payments.
- Project Lifecycle Tracking: Oversee projects from quotation to completion, track their status and progress, and integrate with ImgBB.com for robust image storage and retrieval for each project.
- Automated Invoicing & Payment: Generate professional invoices with automatic PDF export, manage invoice statuses, and record payments, categorizing them as paid, partially paid, or unpaid.
- Real-time Team & Client Chat: Facilitate instant messaging between team members and clients, supporting both text and image attachments for streamlined communication using Firebase's real-time capabilities.
- AI Test Case Tool: Utilize an AI tool to automatically generate detailed test case IDs, scenarios, expected results, and steps based on a brief description of an application feature, improving efficiency in quality assurance.
- Business Performance Dashboard: Provide a centralized overview displaying key metrics such as active projects, total revenue, and pending tasks or bugs for quick business health monitoring.

## Style Guidelines:

- Primary brand color: A deep, professional slate blue (#364E7D), reflecting trust and efficiency in digital work.
- Background color: A very light, subtle cool grey (#F0F2F4), providing a clean and organized canvas for information.
- Accent color: A vibrant, bright sky blue (#5ED6ED), used to highlight calls to action and important interactive elements, adding a modern and dynamic touch.
- Headline font: 'Space Grotesk' (sans-serif), offering a modern, tech-inspired aesthetic. Body text font: 'Inter' (sans-serif), chosen for its excellent readability and neutrality, suitable for displaying large amounts of data and textual content.
- Utilize a consistent set of clean, outline-style icons from a widely recognized library to ensure clarity and intuitive navigation throughout the application.
- Implement a modular, dashboard-oriented layout with a fixed sidebar for navigation and card-based content areas, ensuring responsiveness and clear data hierarchy across all screen sizes.
- Incorporate subtle, functional animations for UI feedback, such as smooth transitions for content loading, form submissions, and modal interactions, enhancing user experience without distraction.
